16 만들기 — 「링크로 레시피 만들기」를 누를 때 로그인 창

문제

  • 로그인 안 한 손님이 하단 「+」를 누르면 「로그인이 필요합니다」 확인 창이 바로 떠서, 레시피 만들기 창을 볼 수 없습니다.
  • 영상 링크를 넣으면 AI가 레시피로 정리해 준다는 것을 보기 전에 로그인부터 묻습니다.
  • 직접 만들기 주소(/recipes/write)로 들어와도 바로 전체 로그인 화면입니다.

제안

  • 로그인 안 한 손님도 「+」를 누르면 회원과 같은 레시피 만들기 창을 열어 주세요. 링크 붙여넣기까지 됩니다.
  • [링크로 레시피 만들기]를 누를 때 로그인 창을 띄웁니다. 그 전에 링크 모양만 확인합니다(인스타 reel·p, 유튜브 shorts·watch·youtu.be). 모양이 다르면 로그인 대신 「이 링크는 만들 수 없어요」를 보여 줍니다.
  • 만들기 창을 내리고, 같은 자리에 12번 로그인 창을 올립니다(두 창을 겹치지 않음). 키보드는 먼저 내립니다.
  • ✕·쓸어내리기·뒤로가기는 링크가 들어 있는 만들기 창으로 돌아갑니다.
  • 붙여넣은 링크를 돌아갈 곳에 함께 실어 주세요(예: returnUrl=/?modal=recipe-create&link=…). 카카오·네이버 로그인은 다른 앱에 다녀오느라 화면이 새로 열려 입력이 사라집니다.
  • 로그인이 끝나면 다시 누르지 않아도 바로 만들기를 시작합니다(버튼 「레시피를 만들고 있어요」).
  • [직접 레시피 만들기]는 그 버튼을 누를 때 로그인 창을 띄웁니다. 4단계를 다 쓴 뒤 로그인하면 쓴 글이 날아갈 수 있어서입니다.
  • 12번의 「로그인을 묻는 곳은 그대로」에서 만들기만 예외입니다.
