v2 변경 (2026-08-13)

① "할인혜택" 붙여쓰기 ② 쿠폰·적립금 라벨 볼드 제거 + 회색(값이 주인공, 라벨은 배경) ③ 절약 스트립을 하단 CTA 바에 붙여 함께 고정 — 스크롤 위치와 무관하게 결제 직전 항상 보이게. 조건: 확정 할인 합계(쿠폰+적립금 사용) > 0원일 때만 노출, 0원이면 바 전체가 CTA만 남음(상단 토글로 확인) ④ 사업자 정보 영역 볼드 제거 — 약관 링크도 회색 일반체

CX 제안 — 적용해둔 것

• 주문자 정보 섹션 삭제: 회원 정보(이름·연락처)를 그대로 쓰므로 결제 단계에서 다시 입력받을 이유가 없음. 기존 화면 스크롤의 최대 원인.
• 배송지 = 요약 카드: 이름+기본 배지+[변경] / 주소·연락처 1줄 / 요청사항 셀렉트만. 주소 입력 폼은 [변경] 진입 시 별도 시트(신규 유저는 첫 주문에만 폼 노출) — 개발 요건.
• 주문 상품 접기: 헤더의 ∧로 접기(재확인 니즈만 대응, 기본 펼침).
• 절약 스트립(에이블리 참고): CTA 직전 "지금 주문하면 2,700원을 아껴요" — 할인 합계(쿠폰+적립금)가 0원이면 미노출. 색은 핑크가 아니라 크림(가이드 면 문법).
• 적립 예정 19P: 금액 행에서 빼고 오늘의집처럼 총액 아래 소형 캡션으로 강등 — 소액일 때 행으로 노출하면 "적립이 의미 없다" 신호가 됨.

CX 제안 — 결정 필요

• 배송비 3,000원의 위치: 결제 직전에 처음 보이면 이탈 요인. 상품 카드의 "파트너 배송" 태그 옆에 "배송비 3,000원"을 미리 표기하거나, 장바구니 단계에서 노출 권장.
• 현금영수증: 가상계좌 선택 시 현금영수증 신청 UI(오늘의집 참고)가 실결제엔 필요 — 이번 프로토엔 미포함, 개발 범위 판단 필요.
• 절약 스트립의 계산 범위: 현재는 확정 할인(쿠폰 2,700)만. 퀵계좌 예상 할인(49원)까지 합산할지는 "확정 전 금액을 약속하지 않는다" 원칙과 상충해 미합산 권장.
