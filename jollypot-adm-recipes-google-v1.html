📐 검색노출 — 반영 원칙 (2026-08-26 확정)
원칙 레시피는 마음껏 만들고, 구글에는 사람이 고른 것만 보여준다. 모든 레시피는 OFF로 생성(대량등록 포함) · ON은 사람의 명시적 행동으로만
ON 조건 에디터 노트 또는 실질 댓글·요리후기가 있을 것 · 유튜브 소스는 신중(자막 재탕 위험), 인스타·직접등록 우선 · 같은 요리명은 대표 1개만
속도 주간 한도(기본 50, 운영 설정값) — 서치콘솔 인덱스율 보며 조정 · ON 전환한 날 서치콘솔 색인 요청까지가 한 동작
자동 안전장치(개발 요건) ①복사본은 영구 OFF + canonical→원본 ②숨김·삭제·신고 시 자동 OFF ③사이트맵에는 ON만(소스별 파일 분리) ④OFF는 meta noindex로(robots.txt 차단 금지) ⑤댓글·에디터노트는 초기 HTML에 포함(SSR) ⑥URL은 ID 고정·301 통일·삭제 시 410
데이터 필드 google_exposure(on/off) · changed_by/at(감사 로그) · cohort(소스 자동) · 노출여부(발행/숨김)와는 별개 축
연동 에디터 노트 저장 화면에 「저장하며 검색노출 ON」 체크박스(한 동선) · 원본 상세에 검색노출 카드(상태+판단 참고+이력)
추가 지시 ①레시피 정보(하위 목록) 화면: 검색노출은 원본 행에만 표시, 복사본 행은 「차단」 고정 배지(전환 불가) ②엑셀 다운로드에 검색노출·노트 유무·변경일 컬럼 포함 ③주간 한도는 월요일 00시 리셋(운영 설정값과 함께) ④대량등록 완료 화면에 「등록된 레시피는 검색 비노출로 생성됩니다」 고지 1줄 ⑤색인 요청 완료 기록은 Phase 2(초기엔 수동 루틴)
