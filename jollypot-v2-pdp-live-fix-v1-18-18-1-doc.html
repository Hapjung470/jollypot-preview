4. 서버 · 데이터 작업

  1. 구매 수 집계 — 1분마다(목표: 30번째 결제 완료 → 화면 표시까지 약 2분 안). ① 1분마다 샵바이 주문 조회(GET /orders)로 최근 3분 사이 결제 완료 · 취소 · 환불된 주문을 받아 졸리팟 표(주문번호 · 상품번호 · 구매자 · 상태 · 결제 시각)에 덮어씀(2분 겹쳐 읽어 빠짐 방지, 주문번호로 중복 방지). 앞 실행이 아직 돌고 있으면 이번 실행은 건너뜀(잠금). 돌릴 곳은 AWS — 지금 쓰는 서버의 정기 작업 또는 EventBridge Scheduler → Lambda 중 편한 쪽(Lambda면 동시 실행 수를 1로 묶어 겹쳐 돌기를 막음) ② 상품별 「오늘 인원」 · 「최근 7일 인원」은 이 표에서 셈. 인원 = 회원은 회원번호로 1명, 비회원은 주문 1건 = 1명. 입금대기 · 취소 · 환불은 뺌 ③ 매일 새벽 한 번 최근 7일 주문을 처음부터 다시 받아 표를 바로잡음 ④ 상품 화면은 숫자를 60초 캐시로 읽음(조회 수만큼 서버를 부르지 않게). 샵바이 판매 수 칸은 누적이고 지금 −999(숨김)라 쓸 수 없음
  2. 베스트 리뷰 자동 지정 — 매일 밤 상품마다 「사진 있음 · 글 20자 이상 · 별 4점 이상」 최신 3개를 베스트로, 나머지 일반으로(PUT /reviews/best-review, 한 번에 1,000개). 리뷰 3개 미만 상품은 지정 안 함. MD가 관리자에서 직접 고른 것은 따로 표시해 덮어쓰지 않음. 베스트에 적립금 없음
  3. 앵콜 · 오픈 알림 — 신청은 샵바이 재입고 알림 API로 받고, 발송은 졸리팟 서버가 알림톡으로(앵콜 판매 시작 · 오픈 때 한 번씩. 카카오 규정상 미리 알림 · 재알림 불가)
  4. 영업일 계산 — 공휴일 자료(공공 특일 정보)
  5. 졸리팟 베스트 상품 — 지금 「같은 카테고리 인기순」 → 몰 전체 인기순(POPULAR)으로, 대표 사진이 같은 상품 하나만 · 짝수 개

간격언제예
4px한 정보의 두 줄정가 → 판매가 · 배송비 → 택배사
8px같은 묶음 안 다른 정보상품명 → 별점 · 택배사 → 발송 상자
14px섹션 제목 → 내용「리뷰 N」 → 카드 · 별점 요약
16px묶음 → 묶음 · 탭 줄 → 첫 내용별점 → 정가 · 혜택 → 배송비
20px큰 사진 → 글 · 1px 선 위아래사진(또는 띠) → 상품명 · 판매가 → 선 → 혜택
24px10px 회색 띠 위아래(섹션 경계)배송 칸 → 띠 → 리뷰 · 더보기 단추 → 띠

모두 눈에 보이는 간격(글자 끝 ↔ 글자 끝, 선 · 사진 · 단추는 테두리)입니다. CSS로 옮길 때 글자 줄 높이 안의 빈칸을 빼 주세요(14px 글자 · 줄 높이 20px이면 위아래 3px씩). 요소가 빠지면 앞뒤 관계로 다시 맞춥니다. 좌우 여백 16px.

7. 확인해 주실 것

  1. 샵바이 주문 조회 API의 호출 한도(1분에 1~2번 부름) · 「상태가 바뀐 시각」으로 조회되는지
  2. 베스트순(BEST_REVIEW) 정렬에서 베스트끼리 · 일반끼리의 순서가 최신순인지(명세에 없음). 아니면 졸리팟에서 다시 정렬
  3. 무료배송 상품을 단순 변심으로 반품할 때 샵바이가 실제로 청구하는 반품 배송비(화면은 왕복으로 안내)
