결제수단 선택 v2 — 대표 피드백 재반영 (2026-08-13)

v1과의 차이: 라디오 리스트 구조 폐기 → 베이비빌리식 큰 버튼 + 퀵계좌이체 히어로 배너로 전환. 실시간 계좌이체 제거. 순서 확정: 퀵계좌이체 → 신용/체크카드 → 간편결제(토스·Npay) → 가상계좌(법인결제 가능).

• 퀵계좌이체 = 히어로: 배너 크기 할애(아이콘+이름+할인 칩), "혜택" 노른자 배지, 기본 선택. 기본 상태에서 0.5% 무제한 할인 문구가 칩+혜택 박스로 이중 노출.
• 간편결제: 버튼 선택 시 아래로 토스/Npay 라디오 펼침(토스 기본). 토스 선택 시에만 계좌 결제 0.5% 할인 박스 노출, Npay는 혜택 박스 없음.
• 가상계좌: 버튼 하단에 '법인결제 가능' 상시 캡션(세금계산서 수요 고객 신호). 선택 시 입금 안내 박스.
• 선택 상태 = 딥그린 2px 보더(베이비빌리의 검정 2px 대응). 혜택 박스 = 피치크림(베이비빌리 회색 박스 대응). 액션 컬러는 결제하기 CTA 하나만.
• 총 결제 금액 아래 예상 할인 캡션: 퀵계좌이체/토스 선택 시 약 183원(36,600×0.5%) 자동 표기, 그 외 숨김. 할인 총액 선반영 금지(결제창 확정 후 적용).

정책·개발 확정 필요

• 퀵계좌이체 상품의 실체 확인: 베이비빌리의 퀵계좌이체는 PG(오픈뱅킹) 상품 — 샵바이 연동 PG에서 동일 상품 제공 여부와 명칭 확정 필수
• 0.5% 할인 재원(자체 프로모션인지 PG 제공인지)과 상한 정책 · 토스페이 지원 여부 · 가상계좌 입금 기한 · 법인결제(세금계산서) 프로세스
