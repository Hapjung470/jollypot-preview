단계 정의

단계화면규칙
1상품상세하단 고정바 [찜][선물하기][구매하기] · 가격은 정가(취소선) → 할인율 + 판매가 3층. "옵션에 따라 금액이 달라져요" 캡션으로 옵션 추가금 예고
2옵션1 선택바텀시트 · 셀렉트 탭 시 목록 펼침 · 항목 = 이름 + 도착 안내 + 추가금(+N원) + [주문많음] · 품절 옵션은 흐리게 표시하되 목록에 남긴다(있는 줄 알고 찾는 유저의 확인 비용 제거)
3옵션2 선택옵션1 선택 전에는 비활성(회색) — 순서를 강제해 잘못된 조합 방지 · 옵션1 선택 시 자동으로 펼침
4선택 완료조합 카드(이름 / 수량 스테퍼 / 금액 / ✕) + 요약 + [장바구니][구매하기] 활성화
✕ 또는 조합 카드 탭 시 옵션1부터 다시 선택

CX 설계 포인트

• 구매하기 버튼은 옵션 선택 전까지 비활성 — 누르고 나서 "옵션을 선택해주세요" 토스트를 띄우는 방식보다 마찰이 적다. 대신 비활성 이유를 버튼 위 캡션("옵션을 모두 선택하면 금액이 계산돼요")으로 상시 안내.
• 도착 안내를 옵션 행마다 반복 — 옵션에 따라 배송이 달라지는 경우가 실제로 있고(세트/색상별 재고 위치), 에이블리도 행마다 표기한다.
• 시트 안에서 쿠폰을 계산하지 않는다 — "주문서에서 적용"으로만 표기. 시트와 주문서에서 서로 다른 금액이 보이면 신뢰가 깨진다.
• 배송비는 예상 결제금액에 합산하지 않고 아래에 별도 표기(+3,000원) — 상품 금액과 배송비를 섞으면 옵션 비교가 어려워진다.
