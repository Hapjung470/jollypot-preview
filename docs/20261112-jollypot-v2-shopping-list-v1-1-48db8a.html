결론 (v1)

  • 장보기 목록은 만듭니다. 여러 레시피 재료를 합치고 구역별로 묶어, 마트에서 체크하며 쓰는 목록입니다. 재료 화면은 「재료 장보기에 담기」 버튼 하나와 줄별 아이콘으로 담습니다.
  • 「쿠팡에 한 번에 담기」는 따라 하지 않습니다. 쿠팡은 장바구니에 담는 API를 주지 않습니다. 해먹으리 방식은 앱 안 웹 화면에서 쿠팡에 대신 요청을 보내는 것으로 보이는데, 쿠팡 파트너스 약관이 「자동화된 수단」을 금지합니다. 느리고, 쿠팡 앱도 안 열립니다(대표님 캡처 그대로).
  • 「한 번에 담기」는 졸리팟 상품으로 합니다. 목록 재료 중 졸리팟이 파는 것은 졸리팟 장바구니에 한 번에 담고 한 번에 결제합니다. 해먹으리는 자기 상품이 없어 못 하는 일입니다. 나머지만 쿠팡 앱으로 하나씩 보냅니다.

쿠팡에 대한 네 가지 질문

질문답
쿠팡은 어떤 API를 주나파트너스 공식 명세: 링크 변환(한 번에 20개), 검색(분당 50회·결과 10개), 카테고리 베스트, 골드박스, 쿠팡 PL, 추천, 실적 보고. 장바구니에 담는 API는 없습니다(명세에 「cart」라는 말 0번). 링크 변환이 받는 주소도 홈·상품·검색·기획전 등 9가지이고 장바구니는 없습니다.
그럼 해먹으리는 어떻게 5개를 담나앱 안 웹 화면(웹뷰)에 쿠팡 모바일웹을 띄우고, 손님 로그인 상태에서 담기 요청을 대신 보내는 방식으로 보입니다(코드는 못 봐서 추정). 쿠팡 파트너스 이용약관 제8조 2항 23호는 「로봇, 스파이더, 스크레이퍼 또는 기타 자동화된 수단을 이용하여 서비스에 액세스하는 것」을 금지하고, 운영정책은 자동화 클릭·쿠키 조작을 영구정지 사유로 둡니다. 쿠팡의 서면 허락 없이 하면 위험합니다.
왜 몇 분씩 걸리나쿠팡은 자동 접속을 막는 장치(아카마이)를 씁니다(응답 쿠키로 확인). 상품을 하나씩 차례로 담고, 그 장치의 확인·로그인 이동·품절 상품 실패 대기가 겹친 것으로 보입니다(추정).
앱이 깔렸는데 왜 「설치되어 있지 않습니다」그 문구는 쿠팡 화면이 띄웁니다(쿠팡 장바구니 화면 원본에 같은 문장). 안드로이드 웹뷰는 다른 앱을 여는 주소를 스스로 처리하지 않고, 웹뷰를 띄운 앱이 직접 앱 열기를 넣어야 합니다(안드로이드 공식 문서). 해먹으리가 그걸 안 넣어서 쿠팡이 「없다」고 판단한 것으로 보입니다. 또 웹뷰 로그인은 쿠팡 앱 로그인과 따로라, 앱으로 넘어가도 다시 로그인해야 할 수 있습니다.
담기를 누르면 쿠팡 앱이 열리면 안 되나하나씩은 됩니다, 여러 개를 한 번에는 안 됩니다. 파트너스 링크는 상품 하나·검색 하나로 가는 링크입니다. 여러 상품을 담은 장바구니로 가는 링크 형식이나 쿠팡 앱 전용 주소는 공식 문서에 없습니다. 그래서 졸리팟은 줄마다 「쿠팡에서 보기」로 쿠팡 앱을 열고, 돌아오면 「봤어요」로 바꿉니다.

졸리팟 설계 (프로토타입 ①~③)

  • ① 레시피 재료 화면: 재료 목록 아래에 「재료 장보기에 담기」(보조 버튼 48px). 누르면 「장보기에 담을 재료」 창이 뜹니다. 소금·식용유·간장·참깨처럼 집에 있을 법한 재료는 꺼진 채로 시작합니다. 줄마다 있는 카트 아이콘은 이제 쿠팡 새 창이 아니라 그 재료 하나를 장보기에 넣고 뺍니다. 넣은 줄은 딥그린 ✓. 담으면 알림 「장보기에 5개 담았어요 · 장보기 보기」.
  • ② 장보기 목록: 저장 화면 칩에 「장보기」를 더합니다(하단 메뉴는 그대로). 담은 레시피 카드(✕로 빼기) → 구역별 묶음(채소 / 두부·달걀·유제품 / 빵·가루 / 양념·소스) → 같은 재료는 합치고 어느 레시피에서 왔는지 작게. 마트에서 누르면 ✓·줄 긋기. 집에 있을 법한 재료는 접어 둡니다. 맨 아래 「온라인으로 사기」와 「카톡으로 목록 보내기」(장 보는 가족에게).
  • ③ 온라인으로 사기: 위 칸 「졸리팟에서 바로 사기」 — 졸리팟이 파는 재료는 [장바구니 담기]로 졸리팟 장바구니에 넣고 한 번에 결제. 아래 칸 「쿠팡에서 찾기」 — 줄마다 쿠팡 앱이 열리고 돌아오면 「봤어요」. 파트너스 고지는 이 창에 둡니다. 가격은 쓰지 않습니다(11/1 결정: 쿠팡 API 결과 저장 금지, 카드는 「쿠팡에서 보기」만).
  • 이름: 「장바구니」는 졸리팟 결제 장바구니 하나만 씁니다. 재료 목록은 「장보기」로 불러, 카트 아이콘이 둘이 되는 혼란을 막습니다.

하지 않을 것

  • 쿠팡·오아시스·오늘의집 장바구니를 대신 채우기 — 공식 길이 없고 약관 위험, 느림.
  • 쇼핑몰 고르기 동그라미 — 졸리팟이 파는 것은 졸리팟, 나머지는 쿠팡 하나로 끝냅니다.
  • 그램을 그대로 사게 하기 — 「300g」 대신 레시피 단위(1모·2개)와 합친 양을 보여 줍니다.

개발 범위 (작은 것부터)

  1. 재료 아이콘을 「장보기 넣기·빼기」로 바꾸고, 「재료 장보기에 담기」 창 추가. 장보기 목록은 회원별로 저장(비회원이면 12번 로그인 창).
  2. 저장 화면 「장보기」 칩: 레시피 카드·구역 묶음·같은 재료 합치기·체크. 구역은 재료 이름 → 구역 표 하나로 시작.
  3. 「온라인으로 사기」: 쿠팡 줄은 지금 쓰는 검색 링크(AFFSRP)를 그대로 씁니다. 앱(웹뷰) 안에서 열지 말고 쿠팡 앱·바깥 브라우저로 넘겨야 쿠팡 앱이 열립니다.
  4. 졸리팟 상품 연결: 처음엔 재료 이름 → 졸리팟 상품 번호 표를 사람이 채웁니다(두부·버터·김치처럼 자주 담기는 것부터). 샵바이 장바구니 담기 API로 여러 개를 한 번에 넣습니다.

볼 숫자 (4주)

  • 레시피를 본 사람 중 장보기에 담은 비율 · 담은 사람 중 일주일 안에 다시 연 비율(해먹으리 4주 재방문 31%와 비교)
  • 「졸리팟에서 바로 사기」로 결제한 금액 · 쿠팡 줄 누른 수
  • 가장 많이 담기는데 졸리팟에 없는 재료 순위 — 다음에 들일 상품 후보(11/1 「소싱 기준선」에 바로 쓰는 숫자)

확인 못 한 것: 해먹으리 앱 안 화면 문구(「온라인 장보기」·「바꾸기」)는 공개 자료에 없어 대표님 캡처로만 확인 · 파트너스 링크가 쿠팡 앱 상품 화면을 바로 여는지에 대한 쿠팡 공식 설명 없음 · 쿠팡 일반 회원 이용약관은 쿠팡 서버가 막아 원문 미확인.
