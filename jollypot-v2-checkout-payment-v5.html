결제수단 선택 v5 — 대표 피드백 반영 (2026-08-13)

v4 → v5 (2026-08-13): 네이버페이 최소화 + 퀵계좌 유도 구조. ① 간편결제ㅣ가상계좌 2단 배치 — 시각 위계가 3티어(히어로 → 표준 → 보조)로 정리되고, 하프 폭 = "보조 수단" 신호. 탭 영역 높이는 유지(접근성). ② 네이버페이는 이중 완충 뒤에 위치: 하프 폭 버튼 + "간편결제" 라벨 안(1탭 추가). 제거가 아니라 강등 — Npay 없이는 결제 안 하는 고객의 전환은 보존. ③ 유도 캡션 확장: 퀵계좌 외 수단 선택 시 "퀵계좌이체로 결제하면 약 183원이 즉시 할인돼요" 상시 노출 — 사실 기반 넛지(다크패턴 아님). ④ 가상계좌 버튼에 "무통장 입금" 보조 라벨(2단에서 이름이 짧아져 의미 보강).

v3 → v4 (2026-08-13): ① 혜택 스트립을 하단으로 이동(기본 적용, 상단·칩은 토글 비교) — 기본 선택 상태에서는 "무엇(퀵계좌이체) → 왜(혜택)" 순서가 자연스럽고, 상단 스트립은 카드 이름보다 혜택이 먼저 읽혀 광고 배너처럼 보일 위험 ② 네이버페이 행 상하 여백 정렬(위 21px/아래 11px 불균형 → 위 12px/아래 14px, 카드 내부 여백선 16px 정렬) ③ 가상계좌 박스를 제목("법인결제 가능")+설명(입금 안내) 구조로 — 볼드 한 줄만 있을 때의 어색함 해소.

v2 → v3: ① 가상계좌 하단 상시 캡션 제거 → 선택 시 크림 박스에 "법인결제 가능"만 노출(입금 안내 문구 삭제) ② 혜택 문구에서 "1원 이상 결제 시" 제거 → "~즉시 할인 · 횟수 무제한" ③ 간편결제에서 toss 제거, 네이버페이 단일(검정 글씨) ④ 혜택 표기 재설계(아래).

④ 혜택 표기 — 왜 어색했고, 무엇으로 바꿨나

v2는 같은 혜택을 세 번 말했다: 떠 있는 노란 "혜택" 배지(내용 없음) + 칩(0.5%) + 혜택 박스(0.5%). 배지는 보더를 끊고 카드 밖에 떠 있어 시각적 소음이었고, 노른자 옐로우는 가이드상 브랜드 IP 전용이라 혜택 시그널로 쓰면 역할이 흐려진다.

• A안 · 상단 스트립 (추천) — 카드 상단 전폭을 크림 스트립으로 쓰고 "결제할 때마다 0.5% 즉시 할인 · 횟수 무제한"을 한 줄로. 배지·칩·박스 전부 제거(스트립이 전담). 혜택이 카드 구조 안에 통합되고, 세로 리듬이 한 단 짧아진다. 쿠팡·토스 카드혜택 스트립과 같은 문법.
• B안 · 인라인 칩 — 배지만 제거하고 이름 아래 칩 유지(검정 글씨 + 숫자만 오렌지). 선택 시 혜택 박스 노출. v2와 가장 가깝고 보수적.
• C안 · v2 배지 — 비교용 보존.
• 공통: 숫자(0.5%)만 오렌지, 나머지 텍스트는 잉크 — 명암비 확보(크림 위 오렌지 본문은 3.0:1로 AA 미달이라 숫자 강조에만 사용).
